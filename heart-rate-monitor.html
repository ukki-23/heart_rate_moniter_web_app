表示
このブラウザは Web Bluetooth に対応していません。Windows の Google Chrome または Microsoft Edge で開いてください。

ウォッチで心拍転送を始めてから「ウォッチを接続」を押してください。選手の人数分くり返します。

詳しい使い方
  1. 心拍転送は、ウォッチの 設定 → センサー → 心拍 → 心拍転送 にあります（機種により異なります）。
  2. 水中では電波が届かないため「最終受信 ～秒前」になります。壁で休んで腕が水面に出ると自動で受信を再開します。
  3. 選手名と最大心拍数はカード上で直接編集でき、ウォッチごとに保存されます。
  4. カード左上の「⠿」をドラッグすると好きなマスに置けます。カードの上に落とすと入れ替わります。
