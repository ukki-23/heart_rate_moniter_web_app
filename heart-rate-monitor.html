心拍モニター

--:--
表示
このブラウザは Web Bluetooth に対応していません。Windows の Google Chrome または Microsoft Edge で開いてください。

使い方
1. ウォッチで「心拍転送」（設定 → センサー → 心拍 → 心拍転送 / 機種により異なる）を開始します。
2. 「＋ ウォッチを接続」を押し、一覧からウォッチを選びます。選手の人数分くり返します。
3. 泳いでいる間（水中）は電波が届かないため「信号なし」になります。壁で休んで腕が水面に出ると自動で受信を再開します。
4. 選手名と最大心拍数はカードの上で直接編集できます（ウォッチごとに保存されます）。
5. カード左上の「⠿」をドラッグすると、好きなマスに置けます（空きマスに移動／カードの上に落とすと入れ替え）。配置は自動で保存されます。
